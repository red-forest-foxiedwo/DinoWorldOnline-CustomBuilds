General Information

Important information and installation instructions.

Prerequisites

  • Required: A Google account.

Utility Mods

A Utility mod is a mod intended to be included in the base of larger mods.

Installing Procedure

  1. Find the correct mod link below.
  2. Open the link using Google Drive.
  3. Read the page thoroughly.
  4. Install the .apk if it is a public file. If it is private, install it after obtaining the required ZIP password.
  5. If the download is an archive, extract it to obtain the .apk.
  6. Install the .apk on a personal Android device if it is signed, or use a VM if it is unsigned.

Password Format

Passwords use the format:

Date_of_Publish + Secret_Code

Example: if the date of publishing is 1 January 2027 and the Secret Code is ABCDEFGHIJ, the resulting password would be:

01012027ABCDEFGHIJ

Ask for the Secret Code when required.
